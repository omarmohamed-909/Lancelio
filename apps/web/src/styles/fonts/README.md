# Bundled interface typeface

IBM Plex Sans Arabic, Regular (400), Medium (500) and SemiBold (600), in WOFF2.

Downloaded unmodified from the [IBM Plex source repository](https://github.com/IBM/plex/tree/master/packages/plex-sans-arabic/fonts/complete/woff2). The copyright and SIL Open Font License are retained in `OFL.txt`, sourced from the [Google Fonts distribution](https://github.com/google/fonts/blob/main/ofl/ibmplexsansarabic/OFL.txt).

`app/layout.tsx` bundles the three local files with `next/font/local`. The application does not fetch a remote font stylesheet or font file at runtime. Keep this license and attribution alongside the fonts when redistributing.
