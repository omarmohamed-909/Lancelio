# خطة دعم اللغات

الحالة: تم تنفيذ دعم العربية والإنجليزية في ١٧ أكتوبر ٢٠٢٦.

## النسخة الأولى

- العربية والإنجليزية، مع تجهيز إضافة لغات أخرى لاحقًا.
- لغة الجهاز هي الافتراضية تلقائيًا: أول لغة مدعومة ضمن تفضيلات المتصفح، من غير خيار إضافي ظاهر في القائمة.
- الاختيار اليدوي المحفوظ له الأولوية على لغة الجهاز.
- لو مفيش لغة مدعومة، نستخدم العربية مبدئيًا للحفاظ على تجربة الموقع الحالية.
- قسم مستقل «اللغة والمنطقة» في الإعدادات: العربية / English، واختيار لغة واضح قبل تسجيل الدخول.
- المظهر الفاتح والداكن يشتغلان مع اللغتين.

## ١. تأسيس نظام اللغة

- [x] تجميع نصوص الواجهة في قاموسين لهما نفس المفاتيح، مع تحقق يمنع غياب ترجمة.
- [x] تحديد اللغة على الخادم قبل عرض الصفحة، من الاختيار المحفوظ ثم تفضيلات المتصفح، ومنع ظهور لغة أو اتجاه غير صحيح عند التحميل.
- [x] حفظ الاختيار للمتصفح وإتاحة تغييره قبل الدخول وداخل الإعدادات.
- [x] ضبط لغة المستند واتجاهه: العربية RTL والإنجليزية LTR.
- [x] الحفاظ على الروابط الحالية وروابط المشاركة واستعادة كلمة المرور، بما فيها الاستعلامات وأجزاء الروابط التي تحمل رموز المشاركة.

## ٢. ترجمة التجربة المشتركة

- [x] الدخول والتسجيل واستعادة كلمة المرور.
- [x] القائمة الرئيسية والبحث والإضافة السريعة والإعدادات.
- [x] الأخطاء والتحقق من الحقول والتأكيدات والتنبيهات وحالات التحميل والفراغ.
- [x] عناوين الصفحات والنصوص المساعدة وتسميات قارئ الشاشة واختصارات لوحة المفاتيح.
- [x] صياغة إنجليزية طبيعية تناسب نفس نبرة المنتج.

## ٣. ترجمة أقسام الشغل

- [x] لوحة المتابعة والعملاء والمشاريع والمهام.
- [x] عروض الأسعار والفواتير والمدفوعات والإشعارات.
- [x] المستندات العامة وبوابة العميل ونوافذ المشاركة.
- [x] توحيد تنسيق الأرقام والتواريخ والعملات وصيغ الجمع حسب اللغة.
- [x] بقاء أسماء العملاء والملاحظات وعناوين المستندات والنصوص التي كتبها المستخدم كما أدخلها.
- [x] الحفاظ على قيم الحسابات وعملة المستند وأرقام الفواتير والتواريخ المحفوظة؛ اللغة تغيّر تنسيق العرض فقط.

## ٤. مراجعة الشكل والاختبارات

- [x] مراجعة محاذاة القوائم والحقول والأسهم وحركة القوائم الجانبية في الاتجاهين.
- [x] بقاء البريد والأرقام التعريفية والروابط واضحة داخل نصوص عربية أو إنجليزية.
- [x] اختبار الموبايل والشاشات القصيرة والوضعين الفاتح والداكن.
- [x] اختبار لغة أول زيارة، ترتيب اللغات المفضلة، الاختيار اليدوي، والريفريش. غياب اختيار محفوظ يرجّع لغة الجهاز تلقائيًا.
- [x] اختبار حفظ المدخلات غير المحفوظة عند التبديل، وروابط المستندات والمشاركة واستعادة كلمة المرور.
- [x] التحقق من اكتمال القواميس وعدم ظهور مفاتيح ترجمة أو نصوص واجهة باللغة الأخرى.
- [x] مراجعة التباين ولوحة المفاتيح وتسميات الوصول في اللغتين، ثم فحص البناء.

## بعد اكتمال النسخة الأولى

نضيف لغات أخرى حسب المستخدمين الفعليين، بقاموس كامل ومراجعة اتجاه وتنسيق واختبارات لكل لغة.

## التحقق من التنفيذ

- اختبارات مستقلة لترتيب لغات المتصفح، اكتمال القواميس، النصوص المتغيرة، الجمع، ودقة المبالغ.
- اختبارات متصفح لاختيار اللغة وحفظها، المدخلات غير المحفوظة، رمز استرجاع كلمة المرور، ١٧ صفحة داخل المساحة، وصفحات العرض والفاتورة وبوابة العميل العامة.
- مراجعة الإنجليزية في الفاتح والداكن عند ١٤٤٠ و٧٦٨ و٣٩٠ و٣٢٠ بكسل، بما فيها شاشة قصيرة بارتفاع ٢٥٦ بكسل، مع فحوصات التباين وتسميات الوصول.
- إعادة اختبار الدخول والعملاء وعروض الأسعار والفواتير والإشعارات والإعدادات والمظهر، مع فحص الأنواع والتنسيق وحدود البنية وبناء التطبيقين.
- الاختبارات محلية على بيانات معزولة؛ لم يحدث نشر أو تعديل لبيانات مستخدمين.
